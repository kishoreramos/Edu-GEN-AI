# Phase 8: Project Demonstration — Video Demonstration Structure & Specifications
## Project: EduGenie — Google Gemini Powered Learning Assistant

---

### 1. Official SmartBridge Video Requirements Summary
The project demonstration video is a mandatory submission component. According to official guidelines, the video must include:
1. **Screen Sharing:** Crisp, full-screen recording showing the live running application.
2. **Student Voice-Over:** Live spoken explanation by the student describing each step.
3. **Core Elements Covered:**
   - Project Name
   - Project Purpose & Problem Addressed
   - Project Benefits & Educational Utility
   - Execution & Working Process (Hands-on walkthrough of all 5 features)
   - Final Output & Verification

---

### 2. Video Technical Specifications

| Parameter | Recommended Specification | Minimum Permissible |
| :--- | :--- | :--- |
| **Duration** | 7 to 10 Minutes | 6 Minutes |
| **Resolution** | 1080p Full HD ($1920\times 1080$) | 720p HD ($1280\times 720$) |
| **Framerate** | 30 fps or 60 fps | 24 fps |
| **Video Format** | MP4 (`H.264` codec, AAC audio) | Standard browser-playable format |
| **Audio Quality** | Crisp spoken narration, no heavy background noise | Audible voice |
| **Hosting Platform** | Google Drive | Mandatory |
| **Access Permission**| **"Anyone with the link can view"** | Mandatory |
